# Airbnb Backend Project

A backend development project inspired by Airbnb, built while learning
Node.js, Express.js, databases, and backend development concepts.

The same project is developed through multiple versions as new technologies
and concepts are learned and implemented.

## 🚀 Live Demo

### Version 1 — Normal

[Airbnb Backend V1](https://airbnb-backend-v1-rsow.onrender.com)

> Note: The free Render instance may take some time to respond after a period
> of inactivity.

## 📂 Project Versions

### Version 1 — Normal

Node.js + Express.js backend with file-based JSON storage.

**Concepts covered:**

- Node.js
- Express.js
- EJS
- Routing
- Dynamic Paths
- MVC Architecture
- Controllers & Models
- CRUD Operations
- Favourites
- Edit & Delete functionality
- JSON file-based data storage
- Tailwind CSS
- Deployment with Render

### Version 2 — MySQL

The Airbnb project is connected to a MySQL database to replace file-based
data storage and practice SQL database operations.

### Version 3 — MongoDB

The project is rebuilt using MongoDB and the MongoDB Node.js driver to
practice NoSQL database operations.

### Version 4 — Mongoose

The project is further developed using Mongoose for schemas, models,
validation, and MongoDB integration.

## 🛠️ Tech Stack

- Node.js
